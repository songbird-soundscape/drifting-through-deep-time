# Drifting Through Deep Time

A knowledge hub that layers moving continents, ancient vegetation, climate, and human migration across 540 million years.

**Live site:** https://songbird-soundscape.github.io/drifting-through-deep-time/
**Guided tour:** https://songbird-soundscape.github.io/drifting-through-deep-time/#tutorial

Part of [The Open Commons of Learning](https://songbird-soundscape.github.io/open-commons/). Everything here is open: grab any code, concepts, or files and build a hub for your own field.

## What's here

- `index.html`: the page and all of its code
- `data/`: plate, biogeography, vegetation, and literature data used by the map and panels
- `sprites/`: images (plants, spores, pollen, and outcrops)

Images and data come from many sources; their credits appear in the site itself. Please keep those credits when you reuse them.
